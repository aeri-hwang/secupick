# secupick

매일 아침 국내외 보안 뉴스, KISA 보안공지, CISA KEV(실제 악용 취약점)를 모아 이메일로 보내 주는 프로그램입니다.
GitHub Actions 에서 돌아가므로 서버도, 매일 승인하는 과정도 필요 없습니다.

## 설치 (처음 한 번, 약 10분)

1. **Gmail 앱 비밀번호 발급**
   Google 계정 → 보안 → 2단계 인증 켜기 → "앱 비밀번호"에서 16자리 비밀번호를 만듭니다.
   (일반 Gmail 비밀번호로는 로그인되지 않습니다.)

2. **GitHub 저장소 만들기**
   GitHub 에서 새 저장소(private 권장)를 만들고 이 폴더의 파일을 전부 올립니다.
   `.github` 폴더도 꼭 함께 올려야 합니다.

3. **Secrets 등록**
   저장소 → Settings → Secrets and variables → Actions → New repository secret
   - `SMTP_USER` : 보내는 Gmail 주소
   - `SMTP_PASSWORD` : 1번에서 만든 앱 비밀번호
   - `MAIL_TO` : 받을 주소 (여러 개면 쉼표로 구분)

4. **첫 실행 테스트**
   저장소 → Actions → "secupick daily" → Run workflow 를 눌러 바로 메일이 오는지 확인합니다.
   이후로는 매일 자동으로 실행됩니다.

## 설정 바꾸기

- **실행 시각**: `.github/workflows/daily.yml` 의 cron 세 줄 (UTC 기준, 한국 시간 -9시간).
  아침 브리핑·낮 알림 시각을 바꾸면 같은 파일의 `SEND_CRON`, `ALERT_CRON`, `ALERT_CRON_LAST` 값도 똑같이 바꿔야 합니다.
- **분류 규칙(취약점·침해사고 단어), 제외할 글, 소스 추가/삭제**: `config.yaml`
- **수동 테스트**: Actions → secupick → Run workflow 에서 send / alert / collect 중 선택
- **소스 점검**: `python main.py check` / **미리보기**: `python main.py dry-run` → `preview.html`

## 하루 일정 (한국 시간)

| 시각 | 하는 일 |
|---|---|
| 07:17 | **아침 브리핑** — 전날 마지막 알림 이후 쌓인 기사를 중복 묶어서 발송 (새 소식이 없어도 발송) |
| 08:02 ~ 18:02, 15분마다 | **낮 알림** — 새 기사 중 이미 보낸 소식과 겹치지 않는 것이 있을 때만 발송 |
| 21:17, 00:17, 03:17, 06:17 | **밤 수집** — 메일 없이 모아 두기만 함 |

빈 시간이 생기지 않도록, 시간대로 기사를 자르지 않고 "아직 안 보낸 기사"를 다음 메일에 넣습니다.
그래서 18:02 이후에 나온 기사는 다음 날 아침 브리핑에, 07:17~08:02 사이 기사는 08:02 알림에 들어갑니다.

## 동작 방식

1. 소스마다 마지막으로 수집에 성공한 시각보다 6시간 앞까지 겹쳐서 확인하므로, 실행이 늦어지거나 한두 번 실패해도 빠지는 기사가 없습니다 (최대 7일까지 따라잡음).
2. 행사·홍보성 글은 빼고 KEV / 취약점 / 침해사고 / 기타로 분류합니다. 개수 제한은 없습니다.
3. 같은 CVE 번호가 나오거나 제목이 비슷한 기사는 하나로 묶고, 나머지 출처는 "같은 소식" 링크로 붙입니다.
4. 최근 3일간 보낸 소식과 같은 소식은 다시 보내지 않습니다. 단, CISA KEV 등재(실제 악용 확인)는 새 소식이므로 항상 보냅니다.
5. 발송에 실패하면 모아 둔 기사를 지우지 않고 다음 메일에 함께 보냅니다.
6. 수집 문제 감시: 접속 실패, 빈 피드, 최신 글이 오래된 '멈춘 피드'(주소가 바뀐 경우)를 문제로 봅니다.
   아침 브리핑 맨 아래에 현재 문제를 모두 표시하고, 낮에 같은 사이트가 연속 3번(약 45분) 문제면 경고 메일을 한 번 보냅니다.
   복구되면 경고 상태가 초기화되어, 다시 문제가 생기면 또 알려 줍니다.
